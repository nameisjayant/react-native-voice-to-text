# react-native-text-to-voice

Customizable speech-to-text for React Native with a voice search dialog and silence auto-stop

## Installation


```sh
npm install react-native-text-to-voice
```


## Usage


```js
import { multiply } from 'react-native-text-to-voice';

// ...

const result = multiply(3, 7);
```
